# Синтетические сценарии (M1)

**Все файлы здесь — синтетика**, придуманная командой для тестов ИИ-руководителя и сквозного цикла.
Это не реальные билеты заказчика (D-050) и не их производные: у них `provenance: "synthetic"`,
пустой `source_ref`, заголовок начинается с «СИНТЕТИКА». Город «Учебный» и улицы вымышлены.
Состав полей карточки D-011 и нормативная маршрутизация здесь не утверждены: службы назначает
мок движка правил, а не сценарий.

| Файл | Решение ДДС | Сценарное состояние вызова |
|---|---|---|
| `syn-001-fire-respond.json` | ответить (`respond`) | соединение сразу; канал оператора 112 выключен (D-030) |
| `syn-002-gas-redirect.json` | перенаправить (`redirect`) | «занято», затем «не отвечает», затем соединение |
| `syn-003-repeat-refuse.json` | отказаться (`refuse`) | обрыв первого соединения после 2-й реплики |

Схема — `contracts/scenario.schema.json` (черновик, M1). Полный формат сценария — M4.
