# Синтетический мини-корпус базы знаний

Все документы в этом каталоге — **явно синтетические**, придуманы командой для
разработки и тестов pipeline (`ai/src/dds_ai/knowledge/`). Они не воспроизводят
содержание реальных документов заказчика (ТЗ, инструкция АРМ-112, классификатор
ЕКП, паспорт РТУ Т16Р, 96 билетов) — эти источники в репозиторий не входят и в
данном окружении недоступны (`docs/ai/agent-prompt.md`, раздел «Важно»).

Формат документа — JSON: поля `doc_id, title, source, section, doc_version,
published_at, approval_status, synthetic` (контракт `SourceDocument`,
`ai/src/dds_ai/contracts/knowledge.py`) плюс `text`. Каждый документ содержит
`"synthetic": true` — pipeline отклоняет документы без этого флага
(`knowledge/documents.py::_validate_corpus`).

Часть документов намеренно содержит выдуманные персональные данные (ФИО,
телефон, e-mail, адрес проживания) — чтобы протестировать обезличивание
(`knowledge/anonymize.py`) до того, как текст попадёт в индекс.

Путь к этому каталогу — не константа в коде: он передаётся вызывающим (`source_dir`
в `build_corpus()`), поэтому настоящий корпус подключается заменой пути, без правок
кода pipeline.
