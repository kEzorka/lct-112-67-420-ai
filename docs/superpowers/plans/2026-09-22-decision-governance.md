# Decision Governance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Утвердить обратимые решения пакетами по 10, проверить каждый пакет на межмодульную совместимость и отразить итог в реестре и Miro.

**Architecture:** Два независимых агента формируют по три предметных пакета. Третий агент последовательно проверяет шесть пакетов по матрице модулей. Главный агент применяет исправления, собирает канонический реестр и обновляет доску.

**Tech Stack:** Markdown, Miro, локальные исходные документы проекта.

**Spec:** `docs/superpowers/specs/2026-09-22-decision-governance-design.md`

## Global Constraints

- Каждый пакет содержит ровно 10 решений.
- Q&A от 16.09.2026 имеет приоритет для трактовки учебного процесса.
- Формально обязательные требования ТЗ не отменяются неявно.
- Неизвестные нормативные факты получают статус `Требует заказчика`.
- MVP использует VoIP-эмулятор, а не полноценный SIP-сервер.
- Обучаемый — только диспетчер ДДС.
- Базовый inference локальный и CPU-first; GPU и облако являются заменяемыми профилями.
