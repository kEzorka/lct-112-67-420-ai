# Лицензии кандидатов STT/TTS — M2/bench-voice

Дата: 28.09.2026 (M2), обновлено 28.09.2026 (bench-voice — узел V). Ничего из
перечисленного **не утверждено** как модель для поставки — это фиксация лицензионного
риска до пилота (раздел 6.2/6.3 промпта, раздел 11: «не объявлять модели STT/TTS
утверждёнными до замера и проверки лицензий»). Источник — файлы `LICENSE`/`COPYING` и
`README` соответствующих репозиториев на GitHub, а также (с обновления сетевой политики,
см. `docs/ai/bench/voice-cpu.md`) карточки конкретных весов на huggingface.co и страница
моделей alphacephei.com — на дату проверки.

**Решение пользователя (28.09, зафиксировано в «Решения оркестратора» `docs/ai/progress.md`,
пункты M2-1/M2-3):** для хакатона некоммерческие модели (Silero, XTTS-v2, F5-TTS) и
`piper1-gpl` допускаются к замеру и демо — это прототип, не поставка; модель подключается
через адаптер и заменяется при внедрении на модель с подходящей лицензией. Ограничения
ниже остаются в силе как входные данные для решения о поставке заказчику.

## Вывод для пилота (не решение, а входные данные для D-040-класса решений)

Обновлено на bench-voice (28.09) после реального замера на весах — см.
`docs/ai/bench/voice-cpu.md`. Хосты huggingface.co/alphacephei.com/models.silero.ai стали
доступны из этого окружения; ниже — то, что удалось перепроверить фактически, а не только
по README репозитория кода.

- **Vosk `vosk-model-small-ru-0.22`** — лицензия подтверждена напрямую (MIT) на странице
  моделей alphacephei.com. Наименьший подтверждённый лицензионный риск среди прогнанных
  STT-кандидатов, но и наихудший WER/CER в замере (см. `voice-cpu.md`) — компромисс
  качество/лицензия/размер, не решение.
- **faster-whisper** — код и веса MIT (конвертация OpenAI Whisper), лучший WER/CER в
  замере среди прогнанных STT-кандидатов; не подтверждена лицензия каждого файла на
  конкретной HF-карточке `Systran/faster-whisper-{small,medium}` отдельно от README.
- **Piper** — голос `denis` (мужской) на датасете CC0 благоприятен для поставки; голос
  `irina` (женский), использованный в замере для D-025, несёт риск: лицензия датасета на
  его карточке — "Unknown". Для поставки заказчику нужен другой женский голос с известной
  лицензией датасета (`piper-voices` содержит несколько женских ru-голосов — не проверены
  здесь из экономии времени, п. `docs/ai/bench/voice-cpu.md`).
- **Silero TTS** — лицензия CC BY-NC-SA 4.0 подтверждена напрямую из файла `LICENSE`
  (раньше — только по README). Некоммерческий риск не снят, использование ограничено
  хакатоном решением пользователя (см. выше); лучший RTF по прогонам с быстрым темпом,
  худший — по пиковой памяти (torch, ≈1.2–1.3 ГБ против ≈350–470 МБ у Piper/onnxruntime).
- **GigaAM**, **T-one**, **XTTS-v2**, **F5-TTS** — не прогонялись в этом замере (время
  контейнера ограничено ~20 мин/кандидат разделом задания); лицензионные заметки из M2
  (GigaAM/T-one — благоприятны по README; XTTS-v2/F5-TTS — явный некоммерческий риск весов)
  остаются актуальными, но не перепроверены по фактическим карточкам весов.
- Ни faster-whisper, ни Piper, ни Silero **не утверждены** как модель для поставки —
  это фиксация результата замера и лицензионного риска, решение — отдельно, после
  юридической проверки и повторного замера на целевом CPU (раздел 11 промпта).
