# Лицензии кандидатов STT/TTS — M2

Дата: 28.09.2026. Ничего из перечисленного **не утверждено** как модель для поставки —
это фиксация лицензионного риска до пилота (раздел 6.2/6.3 промпта, раздел 11: «не
объявлять модели STT/TTS утверждёнными до замера и проверки лицензий»). Источник — файлы
`LICENSE`/`COPYING` и `README` соответствующих репозиториев на GitHub на дату проверки;
страницы моделей на huggingface.co были недоступны из этого окружения (см.
[`docs/ai/bench/voice-cpu.md`](bench/voice-cpu.md)), поэтому лицензии конкретных файлов
весов на HF-карточках не перепроверены отдельно от кода — это отмечено как риск ниже.

## Вывод для пилота (не решение, а входные данные для D-040-класса решений)

- Наименьший лицензионный риск по коду и весам одновременно: **T-one** (STT, Apache 2.0)
  и **Piper** (TTS, MIT-код; но голоса нужно проверять поголосно на HF, недоступном
  отсюда) — но ни то, ни другое не заменяет реальный замер качества (`docs/ai/bench/voice-cpu.md`).
- **GigaAM** тоже выглядит благоприятно (MIT, включая веса по README), специализация на
  русском языке — сильный кандидат для замера в первую очередь, когда сеть будет доступна.
- **Silero TTS**, **XTTS-v2**, **F5-TTS** несут явный некоммерческий риск лицензии весов
  (CC BY-NC-SA / CPML / CC-BY-NC) — использовать в поставке заказчику **нельзя**
  утверждать без отдельного юридического решения, даже если качество окажется выше.
- Ни один кандидат не проверен на фактическую лицензию конкретного файла весов на
  huggingface.co / alphacephei.com / models.silero.ai — эти хосты были заблокированы
  сетевой политикой этого контейнера на момент проверки (28.09.2026). Перед утверждением
  любой модели нужно открыть карточку весов на исходном хостинге и свериться с этой
  таблицей.
