# Оркестрация вех ИИ-контура

Оркестратор — основная сессия. Узлы — отдельные облачные сессии, каждая в своей ветке от `main-ul2qoh`. Оркестратор проверяет узел (`ai/scripts/check.sh` + ревью diff), вливает в `main-ul2qoh`, сводит отчёт `docs/ai/progress/<узел>.md` в `docs/ai/progress.md`, поднимает `CONTRACTS_VERSION` при изменении контрактов и запускает зависимые узлы.

## Граф

```
M0 (готово)
 ├─ A: M1  руководитель без LLM + исполнитель адаптеров
 ├─ B: M2  STT/TTS, замер на CPU, лицензии
 └─ C: M4a база знаний/RAG + NLP-извлечение
 A ──→ D: M3  LLM-реплики, валидатор, защита от инъекций
 C ──→ E: M4b карточки, сценарии, эталоны, gate C-03
 A+B+E → F: M5  оценивание, грамматика, калибровка
 F ──→ G: M6  подсказки, сложность, профиль, рекомендации, аналитика
 все ─→ H: M7  матрица отказов, perf-report, офлайн-прогон, таблица демо
```

## Модели

Opus 5.5 — A, D. Sonnet 5 — B, C, E, F, G, H.

## Когда оркестратор зовёт человека

- выбор модели с лицензионным риском;
- изменение контракта, затрагивающее бэкенд;
- узел дважды подряд не проходит проверку.

## Ограничения

- Исходников заказчика в облаке нет: RAG, сценарии и калибровка — только на синтетике.
- Замеры производительности — не на целевом железе.
